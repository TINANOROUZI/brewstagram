About the proposal

Brewstagram turns a blog-style social app into a coffee community.

The redesign uses warm colors, rounded cards, large imagery, profile-style posts, reactions, comments, and Bootstrap layouts to create a friendly, responsive experience.

Responsive navbar, grid system, cards, buttons, utilities, spacing classes, and mobile-friendly columns.

Mobile design
